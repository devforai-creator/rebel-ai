# Backlogs

This directory is an execution queue, not a document dump.

Use it to answer two questions quickly:

- what should I work from now
- where did older backlog docs go

## Structure

- [active/](./active): current execution backlogs
- [archive/2026/](./archive/2026): completed, parked, or superseded backlog snapshots from 2026

## Current Entry Point

- [core-path-hardening-backlog-2026-04-20.md](./active/core-path-hardening-backlog-2026-04-20.md): current active backlog

## Working Rules

- Prefer one active backlog at a time unless the operating contract changes.
- Move a backlog to `archive/` once it is completed, parked, or replaced.
- Keep policy and direction docs in `docs/`, not in `docs/backlogs/`.
- Archive docs are historical context, not the default source for the next work session.
