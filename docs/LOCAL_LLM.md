# 로컬 RP 모델 연결

배포된 웹에서 사용하려면 [데스크톱 전용 작업자](./LOCAL_WORKER.md)를 사용합니다.
아래 직접 연결 설명은 초기 로컬 개발 연결용입니다.

이 패치는 RebelAI의 호출 경로를 준비합니다. 데스크톱 추론 서버는 별도로
구현·실행해야 합니다. 현재 학습 작업이나 체크포인트는 변경하지 않습니다.

## 첫 연결 범위

노트북의 로컬 RebelAI → Tailscale → 데스크톱의 OpenAI 호환 Chat Completions API.
배포된 Vercel에서는 로컬 공급자를 비활성화합니다.

첫 검증은 독립된 로컬 Supabase와 합성 캐릭터로 진행합니다. 운영 Supabase를
공유하면 클라우드의 백그라운드 작업자가 작업을 가져갈 수 있으므로, 단순히
웹 화면만 로컬에서 띄우는 것으로 실행 위치가 보장되지는 않습니다.
운영 DB 연결과 배포는 이 패치의 검증 범위에 포함하지 않습니다.

## 서버 실행 환경

비밀이 아닌 서버 전용 설정을 .env.local에 추가합니다.

```dotenv
LOCAL_LLM_ENABLED=true
LOCAL_LLM_BASE_URL=http://100.91.59.90:8000/v1
```

주소는 예시입니다. 실제 데스크톱 Tailscale IPv4 주소로 교체하세요.
localhost, 루프백 IP, Tailscale 100.64.0.0/10 IPv4만 허용합니다.
URL에 인증정보·쿼리·프래그먼트를 넣지 않습니다. 리다이렉트를 따르지 않습니다.
NEXT*PUBLIC* 환경변수로 노출하지 않습니다.

작업자 분리 마이그레이션 98 적용 후에는 아래 직접 호출 설정만으로 큐를 처리할 수 없습니다.
LOCAL_WORKER.md의 전용 작업자를 함께 실행해야 합니다.
API 키 화면에서 '로컬 모델 (개인 서버)'를 선택하고 데스크톱 서버에 설정한
전용 인증 토큰(영숫자·하이픈·언더스코어 24~200자)을 등록합니다.
기존 Vault 및 사용자별 소유권 검사를 그대로 사용합니다.
채팅 모델은 '로컬 RP · 원본' 또는 '로컬 RP · FT 2,000행 (step 500)'을 선택합니다.
기존 local-rp 별칭은 지원하지 않습니다. 기존 키의 모델 설정도 새 이름으로 변경하세요.

## 데스크톱 서버 계약

- POST /v1/chat/completions, model: local-rp-base 또는 local-rp-step500.
- Authorization: Bearer <전용 토큰>. 인증 없는 요청을 거부합니다.
- messages의 system/user/assistant 순서와 내용을 보존합니다.
- stream: true이면 OpenAI 호환 SSE delta.content, finish_reason, [DONE]을 반환합니다.
- 비스트리밍 요청에는 Chat Completions JSON을 반환합니다.
- temperature, top_p, max_tokens를 지원합니다. 앱 출력 상한은 2,048토큰입니다.
- 실제 토크나이저로 입력과 출력 예약 길이를 검사합니다. 한도 초과는
  413 또는 422로 거부하고 문맥을 조용히 자르지 않습니다.
- 첫 서버는 기존 비교 도구처럼 thinking을 끄고 검증된 체크포인트를 로드합니다.
- 학습과 동시 실행하지 않습니다. 사용 중이면 409/429/503을 반환합니다.
- 응답 오류에 프롬프트·인증 토큰을 넣지 않습니다.
- 도구 호출은 지원하지 않습니다.

서버의 메모리 한도 및 생성 시간 제한은 실제 모델로 별도 검증해야 합니다.
앱이 표시하는 가격 0은 외부 API 요금이 없다는 의미이며 전기료는 포함하지 않습니다.

## 범위와 남은 검증

채팅 요청 실패 시 다른 공급자로 자동 전환하지 않습니다.
다만 별도로 선택된 요약·임베딩 등 보조 기능은 기존 공급자를 사용할 수 있습니다.
전체 기능이 오프라인이 된다는 뜻은 아닙니다.

자동 테스트는 합성 메시지로 SDK 요청 형식, 스트리밍, 인증 헤더, 주소 제한,
출력 상한 및 오류 비노출을 검사합니다. 실제 데스크톱 서버 연결, 긴 RP 문맥,
UI부터 대화 저장까지의 종단 검증은 서버 준비 후 진행합니다.
